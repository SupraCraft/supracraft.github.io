Accessibility

SupraCraft public sites are designed to remain understandable and operable across keyboard, touch, assistive technology, zoomed and narrow layouts, and light or dark color preferences.

Interaction conventions

  • Primary controls use native HTML semantics wherever practical.
  • Keyboard focus remains visible and a skip link reaches main content.
  • System, Light, and Dark themes preserve the same functional semantics.
  • Essential state is expressed in text rather than color or artwork alone.
  • External destinations are visibly marked and announce that they open in a new browsing context.
  • Navigation among SupraCraft-owned sites remains normal same-tab navigation so browser history continues to work naturally.

Progressive enhancement

Core content and project entry points remain available without JavaScript. JavaScript enhances theme controls and public repository metadata, but does not provide the only path to essential information.

Automated qualification

The organization hub is checked in multiple browser engines for accessibility, keyboard behavior, responsive reflow, theme behavior, navigation semantics, link integrity, and performance budgets before normal publication.
