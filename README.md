# SupraCraft organization hub

Public source for the [SupraCraft project hub](https://supracraft.github.io/).

**Shared craftsmanship, different worlds.**

The hub presents SupraCraft as the shared workbench for focused open-source games, modding tools, creative-play projects, and hobby software. Individual projects keep their own visual identity, documentation, releases, and community context.

The current human-facing visual increment uses a restrained matte presentation, reduced per-project palettes, and a simple continuity rule: a project’s hero image and icon should read as the same object at different scales.

For the organization and its repositories, see:

- [SupraCraft project hub](https://supracraft.github.io/)
- [SupraCraft on GitHub](https://github.com/SupraCraft)
